# ApexGrowth Digital - Modern Agency Homepage

A modern, high-performance, and fully responsive single-page homepage built for a premier **Digital Marketing Agency** client. Engineered with **React 19**, **Vite 8**, modern CSS3 with custom variables, and interactive components.

---

## 🌟 Key Features

1. **Sticky Responsive Navigation Bar**
   - Branded logo with glowing icon badge
   - Smooth desktop navigation with active scroll spy
   - Mobile hamburger menu with smooth slide-out drawer, scroll lock, and touch-friendly links
   - Prominent **"Get Started"** primary action button

2. **Conversion-Engineered Hero Section**
   - High-impact headline with vibrant gradient highlights: *"Grow Your Business With Smarter Digital Marketing"*
   - Dual CTAs: Primary *"Get Started"* and Secondary *"Explore Services"*
   - Live **Marketing Command Center** interactive dashboard preview with simulated growth bars, active campaign statuses, and multi-touch attribution metrics
   - Real-time client rating and optimization badge
   - Trust statistics strip (100+ Projects Delivered, 50+ Happy Clients, 5+ Years Experience, 98.7% Retention)
   - Client trust logos bar (Novasphere, HyperScale, QuantumPay, Lumina Labs, Velocity AI, Aura Home)

3. **About Us Section**
   - Professional narrative positioning marketing as a revenue engine
   - Interactive **Mission, Vision & Core Values** tabbed switcher
   - 4 Key Statistics Cards ($48M+ Client Revenue, 4.8x ROAS, 35+ Specialists, 14+ Industry Awards)
   - Proprietary **The Apex Growth Engine™** 4-stage methodology diagram

4. **Full-Spectrum Services Section**
   - Category filter pills (All, Organic Growth, Paid Acquisition, Brand & Engagement, Technology & Conversion, Retention & CRM)
   - 8 Complete Service Cards:
     1. **SEO (Search Engine Optimization)**
     2. **Social Media Marketing**
     3. **Google Ads / PPC**
     4. **Content Marketing**
     5. **Web Development**
     6. **Branding & Visual Identity**
     7. **Email Marketing & Automation**
     8. **Performance Marketing & CRO**
   - Includes deliverables checklist, impact metrics, hover elevation, and interactive **"Learn More & Scope"** modal

5. **Proprietary Solutions & Software Section**
   - Visually distinct section with dark mesh background and glowing cyan accents
   - 4 Solution Cards with embedded visual mini UI mockups:
     1. **Marketing Automation Suite** (Workflow nodes preview)
     2. **SEO Intelligence Tool** (SERP position tracker preview)
     3. **Social Media Management Hub** (Publishing schedule calendar preview)
     4. **Analytics & ROI Reporting Engine** (Unified ROAS attribution preview)
   - Interactive **"Request Demo"** and **"Inquire Pricing"** actions

6. **Frequently Asked Questions (FAQ) Section**
   - Accordion-style layout with smooth height transitions and accessible ARIA attributes
   - Interactive search bar to filter questions by topic or keyword
   - 7 realistic, comprehensive questions covering timelines, costs, strategies, and ROI
   - Support prompt connecting users to senior strategists

7. **Requirements & Consultation Section**
   - Left Column: Direct contact info (Email, Phone, Headquarters Address, Operating Hours, copy-to-clipboard buttons, and 2-hour response guarantee)
   - Right Column: Interactive Consultation & Requirements Form:
     - Full Name
     - Work Email
     - Phone Number
     - Company Name
     - Service Required (dropdown)
     - Estimated Monthly Budget (dropdown)
     - Project Requirements (textarea)
     - Full frontend validation with inline error messages
     - Loading submission state and confirmation recap card

8. **Comprehensive Site Footer**
   - Agency branding & mission statement
   - Quick navigation links & Core services links
   - Growth Newsletter subscription form with instant feedback
   - Social media vector icons (LinkedIn, Twitter/X, Instagram, YouTube, GitHub)
   - Legal modals (Privacy Policy, Terms of Service, Cookie Policy)
   - Smooth **"Back to top"** button

## 📱 Responsiveness & Browser Testing

The layout is tested and verified at all standard breakpoints with **zero horizontal scrolling**:
- **Mobile Small**: `320px`
- **Mobile Standard / iPhone**: `375px`
- **Tablet / iPad**: `768px`
- **Laptop**: `1024px`
- **Desktop**: `1440px` and larger

- **React 19**

## 🎨 How to Customize Content

All content, branding, services, products, FAQs, and contact details are centralized in a single file:

```
src/data/agencyData.js
```

To update any content:
1. Open [`src/data/agencyData.js`](file:///D:/Home%20Page/src/data/agencyData.js)
2. Edit the company name, phone, email, services, pricing, or FAQs
3. Changes will reflect automatically across all components!

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
